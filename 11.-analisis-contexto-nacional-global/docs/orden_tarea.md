# Orden de tarea

Documento fuente: actividad autónoma grupal para octavo semestre, con apertura 10 de julio de 2026 y cierre 17 de julio de 2026.

El producto es un sistema multiagéntico reproducible para analizar un problema económico ecuatoriano relacionado con el contexto internacional. Debe incluir Ecuador y al menos tres economías de referencia, datos trazables, análisis económico y estadístico/econométrico, dashboard público en Vercel, repositorio GitHub, informe PDF, presentación y evidencia de participación.

Consulte el archivo original proporcionado por el docente para la formulación íntegra y la rúbrica oficial.

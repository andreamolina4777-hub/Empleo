# Protocolo de fuentes

Priorice fuentes oficiales, datos abiertos y artículos verificables. Registre cada una en `config/sources.yaml`.

Lista sugerida: INEC, BCE, MEF, Banco Mundial, FMI, CEPAL, OIT, OMC y organismos estadísticos nacionales. Una URL no basta: identifique conjunto, variable, unidad, periodicidad, cobertura, fecha de consulta y condiciones de uso.

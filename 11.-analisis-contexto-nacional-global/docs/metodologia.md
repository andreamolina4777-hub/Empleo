# Metodología

## Diseño

Complete el enfoque, alcance, unidad de análisis, periodo, países y fundamento teórico.

## Adquisición y transformación

Cada dato debe conservar fuente, URL, fecha de consulta, periodicidad, unidad y licencia. Los archivos originales no se editan. Toda transformación se ejecuta mediante scripts versionados.

## Validación

Se revisan esquema, fechas, duplicados, faltantes, rangos, unidades y consistencia entre fuentes. Las decisiones de imputación o exclusión se justifican.

## Análisis

Describa indicadores, fórmulas, deflactores, tasas, pruebas, modelo, supuestos, diagnósticos y límites de inferencia. Correlación no equivale automáticamente a causalidad.

## Revisión humana

Registre quién validó fuentes, datos, modelo, interpretaciones y versión final.
